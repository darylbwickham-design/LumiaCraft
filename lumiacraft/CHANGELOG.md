# LumiaCraft changelog

## 0.3.0

- Added optional Twitch, YouTube, and unified Lumia chat relay into Minecraft.
- Added `displayname: message` formatting with username fallback.
- Added chat de-duplication, message sanitization, and independent rate limits.
- Added NeoForge, Forge, and Fabric multi-loader setup guidance.
- Added Java 8 Forge bridges for Minecraft 1.12.2, 1.10.2, and 1.7.10 modpacks.
- Added the LumiaCraft logo and CurseForge project link.
- Retained bidirectional gameplay alerts, potion-effect variations, rounded health values, and Pixelboard-compatible alert dispatch.
